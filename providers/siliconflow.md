# SiliconFlow — Provider Page

**At a glance**
SiliconFlow (硅基流动) is an inference cloud hosting **200+ models** — the Chinese open-weight families (DeepSeek, Qwen, GLM, Kimi…) plus image/video/audio — and the **most practical single entry point** for overseas developers who want many Chinese models under one account. Rare among Chinese platforms: it offers **both OpenAI and Anthropic API formats** on the international docs, and its docs explicitly cover integrations (Claude Code, Cline, Cursor, Dify…).

**Last verified: 2026-11-06** (official docs index / llms.txt)

### What's verified
- International docs: docs.siliconflow.com (EN) with full CN mirror — bilingual platform.
- **Dual API formats**: Chat Completions (OpenAI-style) **and** `messages` (Anthropic-style) endpoints — unusual and convenient for Claude-Code-style tooling.
- Capability set: text, vision, video gen, image gen, TTS, reasoning, JSON mode, prefix & FIM completion, function calling, embeddings, rerank.
- Public release-notes page (model/version announcements) — good changelog signal.
- Terms of Use updated Sep 9, 2026 (EN); **CN privacy policy last dated Mar 31, 2025 vs EN Sep 9, 2026** — version skew worth flagging to readers.
