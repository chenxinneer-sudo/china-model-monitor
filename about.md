# About / Methodology

## What this is

China Model Monitor is an independent, English-language reference for the **Chinese AI model API ecosystem**: what the models cost (including peak/off-peak and cache pricing), what the rate limits are, how overseas developers can actually sign up and pay, and what changed this week.

## How we verify

- Every provider page carries a **Last verified** date. Prices are captured from official pricing pages; the source URL is on every changelog entry.
- Fields we could not verify are marked **⚠️ unverified** — we would rather show a hole than a guess.
- Weekly sweep every Friday (P0 providers); full deep-verify (including real sign-up and payment tests) monthly.
- When a provider publishes numbers we cannot reproduce, we publish both theirs and ours, with the discrepancy noted.

## Independence & disclosure

- Provider and model names are used **descriptively** to identify technical compatibility. This site is not affiliated with, endorsed by, or officially connected to any model provider.
- We do not sell rankings. Sponsorships, if any, are labeled and never affect data or wording.
- Referral/affiliate links, once enabled, are labeled inline. Today: **no affiliate links are live**.
- We accept provider-provided evaluation credits only if disclosed on the affected page's changelog.
